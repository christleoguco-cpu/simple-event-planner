FR-01: Create Event

The user can create a new event by entering the following information:

Event Name
Date
Start Time
End Time
Location
Organizer/Provider Name

Example:

Event Name: Women in Technology Workshop
Date: October 10, 2026
Start Time: 2:00 PM
End Time: 5:00 PM
Location: Red Deer, Alberta
Organizer/Provider: Future Tech Organization
